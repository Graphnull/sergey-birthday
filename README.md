# С днём рождения, Сергей!

Персональная поздравительная страница для Сергея, который любит Rust.

Статический сайт без зависимостей и этапа сборки. Основные файлы:
`index.html`, `styles.css`, `script.js`. Все ресурсы используют относительные пути.

## Локальный просмотр

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

Открыть <http://127.0.0.1:8765/>.

## Публикация

GitHub Pages: ветка `birthday-page`, корневая папка `/`.
Изменения в этой ветке автоматически обновляют сайт.

## Проверка

```sh
node --check script.js
```

Проверить страницу на телефоне и компьютере, кнопку запуска, управление
клавиатурой и настройку уменьшения анимации. Pre-commit hook не требуется.
